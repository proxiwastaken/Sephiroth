CONTROLS

Open Inventory - tab 

Open Book - B 

Flip Pages - Q/E

Open Quests -  L

Interact - E

Aim Tongue –  Right Mouse (hold to aim)

Shoot Tongue –  Left Mouse

Retract Tongue – Release 

Latch / Grab Mushroom – Automatic on hit

Pull Object / Enemy – Hold  after latch

Settings - ESC

Scroll - Reel in/out whilst swinging

Jump - space
